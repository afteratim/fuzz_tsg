Excel table names: The purchase table must be named Pur. Excel versions may not allow a table name starting with a number, so name the portal table Table2B (or T2B) if 2B is rejected. The analyzer accepts these aliases. Required columns: DATE, Particulars, Supplier Invoice No., GSTIN/UIN, TAXABLE VALUE, INV VALUE, IGST, CGST, SGST.

Invoice normalization ignores case and whitespace but preserves punctuation and leading zeros to avoid unsafe automatic matches. When enabled, fuzzy matching can mark safe, unambiguous pairs as Fuzzy Matched; pairs failing amount tolerances or having ambiguous alternatives remain in review. Exact matches are processed first.
